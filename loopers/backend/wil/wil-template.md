# WIL - N주차 (주제)

> [!tip]- 작성 전 체크 (쓰고 나서 이 콜아웃은 지우기)
> - 수업 끝나고 **하루 안에** 쓰기. 기억이 생생할 때 쓰는 게 제일 좋다.
> - 잘 쓰려고 애쓰지 않기. 정답보다 **내가 어떻게 생각했는지**가 중요하다.
> - 길이 제한 없음. 짧아도 솔직하면 된다.
> - 남 보여주려는 글이 아니라, 나중에 돌아볼 **내 기록**이다.

## 🧠 이번 주에 새로 배운 것

> [!note]- 가이드
> 무엇을 중점적으로 학습했는지 적는다. 개념 정의를 옮기지 말고, "몰랐던 것 → 알게 된 것"을 내 말로 쓴다.

## 💭 이런 고민이 있었어요

> [!note]- 가이드
> 특히 헷갈렸던 부분, 막혔던 순간을 구체적으로 쓴다. 코드, 에러, 선택지를 적으면 나중에 다시 읽을 때 맥락이 살아난다.
> - 처음엔 이렇게 생각했는데 → 해보니까 아니더라 → 그래서 이렇게 접근해봤다
> - 발제에서 들은 개념을 → 내 코드에 직접 적용해보니 이런 느낌이었다
> - 구조가 잘못됐다고 느낀 이유 → 고친 이유 → 그 결과 생긴 변화
