> [!summary]
> An interactive guide to the Model Context Protocol, the open standard connecting AI apps to tools and data through JSON-RPC over stdio or a single HTTP endpoint. The captured page shows the basic flow: the host lists a server's tools, adds them to the model's context, and makes the `tools/call` itself when the model asks, since the model never talks to a server directly. The live site also covers transports, OAuth, resources, sampling, elicitation, tasks, tool search and codemode, which did not survive the clipping.

## What is MCP?

An open standard for connecting AI apps to the tools and data they use. A server says what it can do, the app shows that to the model, and when the model wants something the app calls the server and hands the result back.

Host

the AI app you use: Claude, Cursor, ChatGPT, an agent

Server

a small program exposing tools, data or prompts

Model

decides what to use; never talks to a server directly

Not REST

JSON-RPC over stdin/stdout or one HTTP endpoint, and servers can talk back

Not just JSON-RPC

JSON-RPC is the envelope. MCP defines what goes in it: the methods, capability negotiation, transports and auth
