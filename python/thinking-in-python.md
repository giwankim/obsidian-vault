> [!summary]
> Landing page and table of contents for Bruce Eckel's *Thinking in Python*, a book on Python insights, idioms, and patterns. Five parts cover foundations (containers, functions, classes, static typing), techniques (testing, dataclasses, pattern matching, decorators, context managers, concurrency), a large design-patterns section rethought for Python, functional programming, and effect management. Book examples and exercise solutions are on GitHub.
